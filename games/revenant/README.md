**Play this: [native-mac](native-mac/README.md)**, our native Apple Silicon
port. It needs no Wine and no Rosetta.

Other versions, kept to test and to compare when there is a problem:

| Version | What it is |
|---|---|
| [other-versions/wine-11-athei](other-versions/wine-11-athei/README.md) | The Windows version on the athei Wine (the default Wine). The reference for the native port. |
| [other-versions/wine-8](other-versions/wine-8/README.md) | The Windows version on Wine 8, kept to compare. |
