# Medal of Honor: Allied Assault (2002)

**Play this: [open-source-port](open-source-port/README.md)**, OpenMoHAA: a
community engine that runs the game natively on the Mac. It needs no Wine and
no Rosetta. It is not our code; our fork of it (with Cmd+Enter for full
screen) is the submodule `open-source-port/openmohaa`. This repository has
the setup: the app launcher, the controller and key settings, and the scripts
that build the engine, take the game data out of the GOG installer, and
install the apps.

It plays the base game and both expansion packs, Spearhead and Breakthrough.
Each one has its own app.

There are no other versions. The game is not set up on Wine.
